# StarBar 1.5.0 — See-through strip and restart announcements

StarBar 1.5.0 makes the track announcement strip easier to live with — you can see what's behind it while you point or type, and it announces a song again when you restart it — and smooths the menu bar's playback and rating transitions.

**This is the recommended release. Requires macOS 13 or later and Music.**

## See through the announcement strip

- Move the pointer near the strip and a soft round hole opens through its background, so whatever is at the bottom of the screen stays visible. The artwork, text and stars stay drawn.
- While you're typing, a larger window opens across the middle of the strip, so the strip no longer hides the text box you're typing in. The background behind the artwork and text is kept so they stay readable.
- Keyboard shortcuts don't count as typing, so rating from the keyboard doesn't clear the strip that shows the rating.
- Both are off when Reduce Transparency is on, because that setting asks for a solid background behind text.

## Announcements

- A song announces again when it goes back to its start (⏮, or Repeat One). Music sends no notification for this, so while announcements are on and a song is playing, StarBar checks the play position every 2 seconds. Nothing is read while paused, stopped, or with announcements off.
- A streamed Apple Music song is no longer announced twice when Music sends a brief Stopped just after it starts.

## Menu bar

- Stars roll into place when playback starts, rating changes animate only the stars that change, and the stars retract before the Add to Library button appears.
- The Add to Library state gives back the menu bar space the stars used, instead of leaving a 64-point gap. On macOS 27 the item narrows while it is empty, so the heart doesn't jump.
- The last strip stays in place through Music's brief gaps between songs, until Music quits.
- Deleting the playing song from your library swaps the stars for the Add to Library button, and a click on the old stars before that refresh no longer saves a rating.
- A rejected drag rating puts the stars back to what Music has.

## Player popover

- Stays open through song changes, including the start of Apple Music songs, and closes when Music quits.
- Points just left of the heart and follows it when the menu bar moves.
- Rounded artwork corners, matching the announcement strip.

## Reliability

- Open at Login now registers only a copy installed in Applications. A development or test build elsewhere on disk had registered itself and kept opening at login instead of the installed app.
- Tests no longer hear real Music notifications or race the host app's own refreshes, which removes several intermittent failures.

## Installation

Download the zip, extract StarBar and move it to Applications. Allow StarBar to control Music when prompted.

This build is signed ad hoc and is not notarised. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. A SHA-256 checksum accompanies the zip.
