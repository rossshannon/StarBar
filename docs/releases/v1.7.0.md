# StarBar 1.7.0 — Liking Spotify songs

StarBar 1.7.0 lets you like and unlike Spotify songs from the menu bar's green heart, once you connect your Spotify account.

**This is the recommended release. Requires macOS 13 or later, and Music or Spotify.**

## Liking Spotify songs

- Press **Connect** next to Spotify in Preferences. Spotify's own sign-in page opens, so your password never passes through StarBar. StarBar asks only to read and change your Liked Songs.
- Once connected, the green heart in the menu bar is filled for a song in your Liked Songs and outlined for one that isn't. Click it to like or unlike the song that's playing. The heart changes at once, and changes back if Spotify refuses.
- The announcement strip shows the same heart before "Spotify".
- StarBar asks Spotify once per new song whether it's liked, and doesn't keep asking, so a song you like in Spotify itself shows as liked the next time it plays.
- **For now, liking works for only a handful of Spotify accounts.** Spotify lets an app it hasn't yet reviewed serve five accounts, each added by hand. Anyone else can sign in, but Spotify then refuses, and Preferences says so. Everything else about Spotify works as in 1.6.0 for everyone.
- Without connecting, nothing changes from 1.6.0: the heart is always filled, and clicking it brings Spotify to the front.
- **Disconnect** in Preferences forgets the sign-in on this Mac. It is kept in a file inside StarBar's own sandbox container, readable only by you.

## Network access

StarBar still downloads the cover art of the Spotify song that's playing, from `i.scdn.co`. If you press Connect, it also talks to Spotify's sign-in server (`accounts.spotify.com`) and Web API (`api.spotify.com`), to sign in and to read and change whether songs are liked. Nothing is sent to either until you press Connect, and nothing goes anywhere but Spotify.

## Preferences

- A new Spotify row with the Connect button and a line saying how the sign-in stands.
- The "Strip style:" label now lines up with its menu.

## Installation

Download the zip, extract StarBar and move it to Applications. Allow StarBar to control Music, and Spotify if you use it, when prompted.

This build is signed ad hoc and is not notarised. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. A SHA-256 checksum accompanies the zip.
